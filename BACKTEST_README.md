# Martingale Backtest Framework

Прогоняет вашу мартингейл-систему (старт 0.01 лот, каждый следующий = сумма открытых × 1.5, до 10 позиций) на **всех инструментах × всех таймфреймах** и ищет самую безопасную комбинацию.

## Файлы
- `backtest_framework.py` — полный фреймворк (все 6 инструментов × 5 ТФ, может тянуть реальные данные из MT5)
- `quick_test_backtest.py` — сокращённый тест (3 × 3), работает без MT5 на синтетике
- `backtest_results.json` — результаты полного прогона (создаётся автоматически)

## Установка
```bash
pip install MetaTrader5 statistics dataclasses_json
```

## Запуск
```bash
# Быстрый тест без MT5 (синтетические данные, ~10 сек)
python quick_test_backtest.py

# Полный тест (все 30 комбинаций)
python backtest_framework.py
```

## Как это работает
1. Для каждого `символ × ТФ` генерируется / загружается история баров
2. Симулируется полная логика бота (без реальных ордеров): открытие, перевороты, закрытие по прибыли или по лимиту 10 позиций
3. Считаются метрики: `win_rate`, `profit_factor`, `max_drawdown`, `total_profit`
4. Вычисляется композитный **Safety Score = (win_rate/100) × (1+min(PF,10)) / (1+abs(maxDD))**
5. Выводится топ комбинаций

## Метрики безопасности
- **Win Rate** — % выигрышных циклов
- **Profit Factor** — gross_profit / gross_loss
- **Max Drawdown** — максимальная просадка за тест (КЛЮЧЕВАЯ метрика для мартингейла)
- **Safety Score** — чем выше, тем безопаснее (учитывает win_rate, PF и DD)

## Важно понимать
Результаты на синтетике — это ДЕМОНСТРАЦИЯ логики. Для реального выбора инструмента/ТФ нужно:
1. Запустить с реальными данными из MT5 (`use_real_data=True`)
2. Использовать минимум 3-6 месяцев истории
3. Делать walk-forward (обучающая / тестовая выборки)
4. Учитывать реальный размер депозита и маржинальные требования

⚠️ Мартингейл — стратегия с отрицательной математической ожидаемостью. Бэктест показывает win_rate 90%+, но редкие убыточные циклы стирают весь профит. ВСЕГДА тестируйте на демо-счёте.
