# Martingale Universal Backtest Framework v2

Прогоняет вашу мартингейл-систему на **всех инструментах × всех таймфреймах** и находит самую безопасную комбинацию.

## Что исправлено в v2

- ✅ Сохранение JSON в папку `results/` рядом со скриптом (работает на Windows и Linux)
- ✅ Фильтрация по датам (`history_from` / `history_to` в `Config`)
- ✅ Вывод топ-5 комбинаций для торговли
- ✅ Защита от деления на ноль в SafetyScore
- ✅ Обработка ошибок MT5 (автоматический fallback на синтетику)

## Быстрый старт

```bash
# 1. Быстрый тест (синтетика, без MT5) — ~30 секунд
python backtest_framework_fixed.py
# -> выберите 1

# 2. Полный тест (синтетика, 6 инструментов × 5 ТФ = 30 комбинаций)
python backtest_framework_fixed.py
# -> выберите 2

# 3. Реальные данные из MT5 (нужен запущенный терминал MetaTrader 5)
python backtest_framework_fixed.py
# -> выберите 3
```

## Результаты

После завершения в папке `results/` появится файл `backtest_results.json`
с полной статистикой по всем комбинациям.

## Настройка периода истории (только для реальных данных MT5)

Откройте `backtest_framework_fixed.py`, найдите класс `Config` и укажите даты:

```python
@dataclass
class Config:
    ...
    history_from: Optional[str] = "2024-01-01"   # начало периода
    history_to:   Optional[str] = "2024-06-30"   # конец периода (None = до сегодня)
```

## Интерпретация результатов

| Метрика | Что означает |
|---------|--------------|
| **Win%** | Процент циклов, завершившихся в плюсе |
| **PF (Profit Factor)** | Отношение прибыли к убытку (999 = все циклы в плюсе) |
| **MaxDD** | Максимальная просадка equity (чем меньше, тем безопаснее) |
| **Total** | Итоговый профит за весь период |
| **SafetyScore** | Комплексная оценка безопасности (win_rate × PF / DD) |

## Важно

⚠️ Мартингейл — стратегия с **отрицательной математической ожидаемостью**.
Даже если win_rate = 98%, редкие убыточные циклы могут стереть весь профит.
**Обязательно тестируйте на демо-счёте и добавьте риск-менеджмент.**
