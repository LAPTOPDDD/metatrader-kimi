🎯 Цель Скрипта

Этот скрипт реализует "Base"-линию торговой стратегии. Он предназначен для честного сравнения с более сложными версиями (V2 Full), поэтому из него намеренно удалены:

  • Stage 2 (Кросс-активные "головы" нейросети).
  • Мета-контроллер риска (динамическое управление размером позиции).

Остается чистая логика: Stage 1 (индивидуальные модели для каждой пары) и Равновесный портфель.

📂 1. Загрузка и Подготовка Данных

Скрипт работает локально с файлами CSV из папки data/.

Функция pair_features(sym)

Это "сердце" подготовки данных для одной валютной пары:

  1. Загружает базовый ТФ (M15).
  2. Вычисляет технические индикаторы через q6.FeatureStore.
  3. Мульти-ТФ Синтез: Для каждого бара M15 находит соответствующий бар на старших ТФ (M30, H1, H4) и добавляет их фичи к текущей строке. Это позволяет модели "видеть" старший контекст.
Важно: Данные выравниваются по времени. Если на старшем ТФ нет бара, берется последний известный (forward fill logic via searchsorted).

🎯 2. Формирование Цели (Target)

Мы не предсказываем цену напрямую. Мы предсказываем направление сглаженного тренда.

def make_target(close, sigma):
  smoothed = gaussian_filter1d(close, sigma)
  deriv = np.gradient(smoothed) # Производная (скорость изменения)
  return (deriv > 0).astype(int) # 1 если растет, 0 если падает

Это делает модель устойчивой к рыночному шуму.

🔄 3. Walk-Forward Валидация

Чтобы избежать "подгонки" (overfitting), используется скользящее окно:

  • Train: Бары [0 ... tr_end]. На них обучается LightGBM.
  • Test: Бары [tr_end ... te_end]. На них проверяется качество.
  • После теста окно сдвигается на FOLD баров вперед, и процесс повторяется.

Нормализация (StandardScaler) фитится только на Train-части, чтобы не заглядывать в будущее.

💰 4. Торговая Логика (Portfolio)

В функции run_fold происходит магия торговли:

  1. Модель предсказывает вероятность роста (predict_proba).
  2. Если вероятность > 0.5 → Сигнал +1 (Long).
  3. Если вероятность ≤ 0.5 → Сигнал -1 (Short).
  4. Равновесный портфель: Доля каждой пары одинакова. Risk Scale = 1 (без дополнительного контроля риска).
  5. Доходность портаеля = среднее арифметическое доходностей всех пар с учетом знаков сигналов.
