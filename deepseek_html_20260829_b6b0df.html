1 Загрузка & признаки

  • load_pair_tf() — чтение CSV для каждой пары и таймфрейма
  • pair_features() — строит мульти‑ТФ матрицу:
    • базовый M15 + старшие (M30, H1, H4) через FeatureStore из QWEN6
    • интерполяция по времени (поиск ближайшей свечи старшего ТФ)
  • make_target() — цель (бинарная) на основе производной сглаженной цены (гауссовский фильтр с σ=1.5)
  • возвращает: X (признаки), y (цель), ret (доходности) для всех пар
# пример: X.shape = (бары, признаки_базовые + признаки_старших_ТФ) # цель: 1 если производная >0, иначе 0

2 Stage‑1 (каждая пара)

  • для каждой валютной пары обучается своя модель (из модуля QWEN6): q6.train_model() — классификатор
  • предсказания → вероятности proba1[s] → сигнал ±1 (порог 0.5)
  • никакого Stage2 (кросс‑активные головы) — только собственная модель пары
  • сигналы всех пар объединяются в матрицу sig размером (бары × число пар)
🔹 Базовая логика: каждая пара решает сама за себя, без кросс-влияния

3 Портфель & риск

  • равновесный — все пары имеют одинаковый вес (1 / P)
  • scale = 1 (без риск‑контроллера, без мета‑уровня)
  • доходность портфеля на шаге t: pr[t] = mean( sig[t] * ret[t] ) (среднее по парам)
  • никакого динамического управления размером позиции, никакого «мета-контроллера риска»
абляция убраны Stage2 и мета-контроллер

4 Walk‑forward & оценка

  • BARS_TRAIN=1000 — первое обучающее окно
  • FOLD=90 — длина тестового окна, шаг прокрутки
  • N_FOLDS=10 — число окон (или пока хватает данных)
  • на каждом фолде: нормировка фич (StandardScaler) на train-статистике
  • сохраняется эквити eq = cumprod(1+pr), график в PNG и CSV
📈 Итоговые метрики: доходность %, максимальная просадка (maxDD)
📁 данные (CSV) → признаки M15+старшие → цель (производная) → Stage‑1 (модель/пара) → сигналы ±1 → портфель (равный вес) → эквити

Что делает wide_brainV2.1.py (абляция)?
  • Загружает исторические данные для всех пар (или указанных) по нескольким ТФ.
  • Строит мульти‑таймфреймовые признаки и бинарную цель (наклон сглаженной цены).
  • Обучает отдельную модель для каждой пары на основе её собственных признаков (Stage‑1).
  • Генерирует сигналы (шорт/лонг) и формирует равновесный портфель без дополнительных слоёв риска.
  • Проводит walk‑forward (скользящее окно) с фиксированным шагом, сохраняет эквити.
  • Выводит итоговую доходность и максимальную просадку, строит график эквити.
