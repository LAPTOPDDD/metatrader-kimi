2. ЯДРО СИСТЕМЫ: ПЕРВАЯ ПРОИЗВОДНАЯ ГАУССА

2.1 Алгоритм формирования целевой переменной

# Вход: ценовой ряд close (массив цен закрытия)
# Параметры: sigma (сглаживание Гаусса, оптимизируется 0.5-3.0)

# Шаг 1: Сглаживание Гаусса
smoothed = gaussian_filter1d(close, sigma, mode='reflect')

# Шаг 2: Первая производная (градиент)
deriv = np.gradient(smoothed)

# Шаг 3: Целевая переменная (бинарная классификация)
Target = (deriv > 0).astype(int)  # 1 = вверх, 0 = вниз
⚠️ 2.2 КРИТИЧЕСКИ ВАЖНО: Удаление краевых эффектов (дребезг)

ПРОБЛЕМА:

  • При применении гауссова фильтра края последовательности имеют артефакты
  • Производная на краях недостоверна (ложные сигналы)
  • Длина "дребезга" зависит от sigma

РЕШЕНИЕ:

# Рассчёт безопасного margin (запаса)
margin = int(3 * sigma)

# КРИТИЧЕСКАЯ ФОРМУЛА:
# margin = 3 сигмы отрезаем с КАЖДОГО конца
# Общее количество отрезаемых баров = 2 × margin = 6 × sigma

# Примеры:
# sigma = 1.0 → margin = 3 бара с каждого края (всего 6 баров)
# sigma = 2.0 → margin = 6 баров с каждого края (всего 12 баров)
# sigma = 3.0 → margin = 9 баров с каждого края (всего 18 баров)

# Обрезка данных
start = margin
end = len(deriv) - margin

X = features.iloc[start:end]      # Признаки
y = deriv[start:end] > 0          # Целевая переменная

ПОЧЕМУ 3 СИГМЫ:

  • Гауссово распределение: 99.7% данных в пределах ±3σ
  • Производная стабилизируется после 3σ
  • Меньше 3σ → остаточный дребезг
  • Больше 3σ → потеря полезных данных

# Если классов неравномерно (0 и 1)
n_pos = sum(y == 1)
n_neg = sum(y == 0)

sample_weight = np.where(
    y == 1, 
    n_neg / n_pos if n_pos > 0 else 1.0,  # Вес для класса 1
    1.0                                     # Вес для класса 0
)

model.fit(X, y, sample_weight=sample_weight)

if current_atr < median_atr * atr_multiplier:

7. СТОПЫ И ТЕЙК-ПРОФИТЫ

7.1 Фиксированные TP/SL

# Для H1: TP ≥ 30 пипсов, SL ≥ 20 пипсов
# Для H4: TP ≥ 50 пипсов, SL ≥ 30 пипсов

tp_distance = tp_pips * pip_size
sl_distance = sl_pips * pip_size

# BUY:
entry_price = close + spread/2
tp = entry_price + tp_distance
sl = entry_price - sl_distance

# SELL:
entry_price = close - spread/2
tp = entry_price - tp_distance
sl = entry_price + sl_distance

7.2 Динамический TP/SL (на основе ATR)

# Адаптация к текущей волатильности

current_atr = ATR(14)[current_bar]

if use_dynamic_tp_sl:
    tp_distance = current_atr * dynamic_tp_atr  # 1.5-3.0
    sl_distance = current_atr * dynamic_sl_atr  # 0.5-1.5

7.3 Трейлинг-стоп

# Двигает SL вслед за ценой (только в прибыль)

if use_trailing and bars_held >= min_hold_bars:
    trailing_distance = trailing_pips * pip_size
    
    if position == BUY:
        max_price = max(highs[entry_bar:current_bar])
        new_sl = max_price - trailing_distance
        
        if new_sl > current_sl and new_sl > entry_price:
            current_sl = new_sl  # Двигаем SL вверх
    
    if position == SELL:
        min_price = min(lows[entry_bar:current_bar])
        new_sl = min_price + trailing_distance
        
        if new_sl < current_sl and new_sl < entry_price:
            current_sl = new_sl  # Двигаем SL вниз

11. КРИТИЧЕСКИ ВАЖНЫЕ ДЕТАЛИ

11.1 Краевые эффекты (дребезг) 
# САМОЕ ВАЖНОЕ ПРАВИЛО:
margin = int(3 * sigma)  # Баров с КАЖДОГО конца

# Примеры:
sigma = 1.0 → margin = 3 бара (всего 6 баров удаляется)
sigma = 2.0 → margin = 6 баров (всего 12 баров)
sigma = 3.0 → margin = 9 баров (всего 18 баров)

# Почему 3 сигмы:
# - 99.7% гауссова распределения в пределах ±3σ
# - Производная стабилизируется после 3σ
# - Меньше → остаточный шум на краях
# - Больше → потеря полезных данных

# ВСЕГДА проверяй:
if margin * 2 >= len(data):
    margin = int(len(data) * 0.1)  # Fallback 10%
11.2 Учёт спреда 
# BUY: вход по ASK (close + spread/2)
# SELL: вход по BID (close - spread/2)

# Выход:
# BUY → выход по BID (close - spread/2)
# SELL → выход по ASK (close + spread/2)

# Спред УЖЕ учтён в расчёте PnL!
11.3 Размер пипса
